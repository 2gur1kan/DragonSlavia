# 🐉 DragonSlavia

> A small tribute to the golden days of LAN gaming.

DragonSlavia is a small multiplayer-focused game project inspired by the classic LAN gaming experience.

The project was created as a personal game development project with a focus on recreating the feeling of gathering with friends, starting a local game, and simply having fun together.

---

## 🎮 About the Project

DragonSlavia is a Unity-based game project built around the idea of bringing back the atmosphere of classic LAN gaming.

Rather than focusing on large-scale production, the project explores the fundamentals of multiplayer game development, gameplay systems, and creating a fun experience for small groups of players.

The project is also part of my ongoing game development portfolio and experimentation with Unity.

Game Download : https://systembug.itch.io/dragonslavia

---

## ✨ Features

- 🎮 Multiplayer-oriented gameplay
- 🖥️ Unity-based development
- 🌐 LAN / local multiplayer concept
- 🧩 Modular gameplay systems
- 🎨 Custom game assets and environments
- 🔧 Gameplay experimentation and prototyping

> The project is currently under development and features may change as development continues.
